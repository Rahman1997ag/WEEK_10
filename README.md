# Salary Calculator - Week 10 Tutorial

## Description
This project is a simple salary calculator for HR departments. It collects employee information and computes gross salary, EPF (11%), SOCSO (0.5%), and net salary. It also includes overtime pay (RM25/hour) and a bonus reward for employees with more than 3 years of service.

## Files
- `main.py` – orchestrates the workflow.
- `employee.py` – collects employee details.
- `salary.py` – performs all salary calculations.
- `report.py` – displays the salary report.
